# 🛡️ PhishWarden MJ - Panel Web Administrativo

Plataforma web responsiva para el personal de TI y administradores de ciberseguridad. Permite diseñar plantillas de ingeniería social, administrar grupos de usuarios, programar campañas de simulación de phishing/smishing y monitorear el nivel de vulnerabilidad de la organización mediante dashboards e informes gráficos en tiempo real.

---

## 🚀 Tecnologías y Herramientas

* **Framework Web:** Next.js (React)
* **Estilos & UI:** Tailwind CSS + Shadcn UI
* **Visualización de Datos:** Recharts (Dashboard, mapas de calor y gráficos estadísticos)[
* **Cliente HTTP:** Axios / Fetch API
* **Despliegue & Hosting:** Vercel

---

## 💻 Características Principales

* **Editor de Plantillas:** Creación y modificación de plantillas de phishing/smishing con vista previa.
* **Gestión de Usuarios:** Carga masiva de personal (.csv/Excel) y organización por departamentos.
* **Programación de Campañas:** Envío masivo o escalonado de pruebas simuladas.
* **Dashboard Estadístico:** Métricas dinámicas de apertura, clics e interacciones en tiempo real.
* **Reportes Exportables:** Generación de informes ejecutivos en PDF y Excel.
